PROBLEM STATEMENT: 2D CONSOLE GRAPHICS EDITOR IN C

Write a 2D graphics editor using '*' and '_'.
Write functions to draw a circle, rectangle, line, and triangle.
You should be able to:
- Add objects to the picture
- Delete objects from the picture
- Modify objects in the picture
Use a 2D array of characters to store the picture.
Write a function to display the picture.
Language: C


MY COLLABORATION WITH ANTIGRAVITY (HOW I SOLVED & INTERACTED)

I implemented this assignment using a collaborative approach with Antigravity, my AI coding assistant. Here is how the process unfolded:

1. Initial Code & Concept Setup:
   I began writing the base logic by setting up the 2D character canvas grid and rendering variables in program.c. However, I realized that drawing shapes directly onto the character grid made it impossible to delete or modify shapes later (since we lose track of which '*' belongs to which shape). 

2. Clarifying Doubts & Asking Questions:
   I asked Antigravity for guidance on how to write the coordinate equations and shape logic. I specifically asked:
   - Should we ask the user for inputs like slope, radius, or area, or just define them statically in the code?
   - How can we write robust rendering algorithms for console-based text pixels?

3. Hints and Math Verification:
   Antigravity clarified that asking a user for slope is counter-intuitive for lines; instead, we should take start/end points and calculate the steps. For circles, it explained the math of discrete circle equations: (x - cx)^2 + (y - cy)^2 ≈ r^2 and proposed Bresenham's circle drawing and line drawing algorithms to use fast integer-based arithmetic instead of slow floating-point operations.

4. Bug Detection & Troubleshooting:
   When developing the coordinate updates, I had syntax/compilation issues around function headers, and the standard scanf input was causing infinite loops when characters were accidentally entered. Antigravity detected these issues, corrected the errors in my functions, and suggested a safe fgets/sscanf parser routine to make the input system robust.

5. Final Integration:
   Under Antigravity's guidance, I structured a clean Shape database system in C supporting line, rectangle, circle, and triangle updates (CRUD actions) and finalized the interactive menu.


PROJECT FEATURES

1. Canvas Buffer: Initialized to background character '_', rendered using '*'.
2. Custom Coordinate Guide System: Horizontal and vertical coordinates are printed alongside the border to make it easy for users to coordinate placement.
3. Bresenham's Line Algorithm: Efficient integer-based line calculation.
4. Midpoint Circle Algorithm: Mathematically correct circle outline rendering.
5. Shapes Database CRUD:
   - Add: Interactive inputs for coordinates, width, height, radius.
   - List: View all active shapes in memory with their properties and IDs.
   - Modify: Re-enter shape coordinates/dimensions for any target shape ID.
   - Delete: Remove a shape by ID, sliding memory segments to compress space.
6. Robust User Input: Helper routines that validate integer ranges to prevent scanf buffer loops.
